# スライド制作

記事・原稿を動画用スライドに変換する。**ゴールは「あとは読み上げるだけ」の状態で渡すこと。**

引数があれば対象（記事のパス・URL・テーマ）として扱う。なければ直前の文脈から判断し、曖昧なら何をスライド化するかだけ確認する。

## 原則

- 途中で止めて確認を挟まない。構成から Canva のメモ欄まで**黙って最後まで通す**
- 画像だけ渡しても収録できない。**台本まで必ずセットで作る**
- 1枚 = 1メッセージ。詰め込まない

## 手順

### 1. 構成を設計する（10枚前後）

タイトル → なぜ（課題提起）→ 本編 → チェックリスト → まとめ、の流れを基本にする。
枚数は内容量で決めてよいが、増やすより1枚あたりを絞る。

### 2. 各スライドの「載せる内容」と「読み上げ台本」を両方書く

台本は聞き取りやすい短文にし、**改行を息継ぎ位置**にする。書き言葉のまま置かない。

この時点で原稿ファイル（構成・内容・台本を1つにまとめたmd）をプロジェクト内に保存する。

### 3. ChatGPTで画像生成

Chromeで開いているユーザーのChatGPTを使う。

- 最初に**【共通スタイル】を1回だけ**投げる
- 以後は「同じトーン・同じ配色・同じサイズで」＋各スライドの**内容だけ**を1枚ずつ
- まとめて頼むと品質が落ちる。必ず1枚ずつ

#### レイアウトは指示しない（重要）

各スライドで **「上部に」「中央に3つのカードを横並びで」「下部の帯に」といった配置の指定はしない。**
渡すのは**見出し・本文・まとめの一言といった中身だけ**。並べ方はChatGPTに任せる。

悪い例（配置を指示している）
```
上部に「このレッスンのゴール」。
中央に2つの白い角丸カードを縦に並べる。
下部のネイビー帯に白文字で「幻想を手放した先に…」。
```

良い例（内容だけ）
```
見出し「このレッスンのゴール」
・誰でもできることで稼ぎ続けるのは不可能だと腹落ちする
・参入障壁のあるビジネスを選ぶ理由を、自分の言葉で説明できる
まとめ「幻想を手放した先に、積み上がる利益がある」
```

#### デザインの既定（共通スタイルで1回だけ指定する）

- **白青基調**
- **フォントは Noto Sans JP**
- 16:9（1920x1080）
- 1枚1メッセージ。文字は大きく、遠くから読めるサイズ
- 余白・詰め込み具合まで指定しない。デザイン判断はChatGPTに任せる
- 指定した文字列をそのまま正確に描画する（誤字を防ぐ）

ユーザーから別の指定があればそちらを優先する。

**入力欄への投入は `computer type` を使わない。** 数字・括弧が欠落する。
`div[contenteditable="true"]` にフォーカスして `document.execCommand('insertText', false, text)` で入れる。

会話は**5枚前後で劣化する**。おかしくなったら新しいチャットを開いて共通スタイルから やり直す。

### 4. 画像をローカルに回収

**クリップボードは使わない**（他セッションと競合して固まる）。ページ内fetchもCSPで通らない。
確実なのは **window.name リレー**。詳細は `references/image-relay.md`。

保存後は**必ず目視確認**する。再生成が挟まると1枚ズレる。

### 5. PDF化

`file_upload` は1回10MBまで。PNGのままでは入らないので必ず変換する。

JPEG（q92, 1920px）に変換 → HTMLに1ページ1枚並べて `@page{size:1920px 1080px;margin:0}` → headless ChromeでPDF化。

### 6. Canvaにアップロード

新規プレゼンテーション → 左「アップロード」→ 隠しfile inputをJSで可視化 → `file_upload` でPDFを投入 → デザインタブに出た項目をクリック → **「Nページすべてに適用」**。

1枚ずつ配置するより確実。

### 7. 各ページのメモ欄に読み上げ台本を入れる

**ここが一番ハマる。** 手順とハマりどころは `references/canva-notes.md` を必ず読むこと。

### 8. 仕上げ

デザイン名を付ける。ユーザーには「あとは読み上げるだけ」で渡す。

## 画像を差し替えるとき

既存デッキの一部だけ作り直す場合は `references/canva-notes.md` の「画像差し替え」を見る。
**Deleteキーはページごと消える**ので使わない。
