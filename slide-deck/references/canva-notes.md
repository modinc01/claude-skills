# Canva操作のハマりどころ

## メモ欄に台本を入れる

### ページ移動

**サムネイルのダブルクリックは使わない。** リネームモードに入る。

正しい手順は `キャンバスを実クリック → Escape → PageDown / PageUp`。
JS実行のたびにフォーカスが外れるので、**毎回キャンバスをクリックし直す**。

現在ページ番号は `span` の「Nページ」テキストから読む。

```js
[...document.querySelectorAll('span')].find(e => /^\d+ページ/.test(e.textContent.trim()))
```

**書き込む前に必ずページ番号を照合する。**

### textareaの選び方

古いノードが残っていて誤読するので、両方の条件で絞る。

```js
[...document.querySelectorAll('textarea')]
  .filter(e => e.maxLength === 5000 && e.offsetParent !== null)
```

`offsetParent !== null`（表示中）が抜けると、見えていないtextareaを掴んで「書けたつもりで空」になる。

### 書き込み手順

1. メモ欄を**実クリック**（JSのfocus()では足りない）
2. `cmd+a` → `Delete`（**実キー**で）
3. `document.execCommand('insertText', false, text)` で本文投入
4. **キャンバスを実クリックしてblur** ← これで確定する

**blurしないと保存されない。** ここを飛ばすと全部消える。

### 検証

書き込み後は **PageUpで戻りながら全ページ検証する。**
文字数を数えて照合するのが確実。

## PDFのアップロード

新規プレゼンテーション → 左「アップロード」→ 隠しfile inputをJSで可視化 → `file_upload` → デザインタブに出た項目をクリック → **「Nページすべてに適用」**。

1枚ずつ配置するより確実で速い。

## 画像差し替え（1ページだけ作り直すとき）

1. 差し替えたいページを表示し、**画像を1回クリックして選択ハンドルを出す**
2. 削除は**フローティングツールバーのゴミ箱アイコン**を押す
   - **Deleteキーは使わない。** 画像ではなく"ページ"が選択されている状態だと**ページごと消える**（実際に12→11になった。cmd+zで復旧）
3. 画像を消すと、下に隠れていた**テンプレート既定の背景グラフィック（雲と丘のイラスト）が露出することがある**。これも選択してゴミ箱で削除する
   - 残したまま「背景として設定」すると、**新しい画像が雲の後ろに回り込んで見えなくなる**
4. 左「アップロード」パネルのサムネイルを**クリック**して挿入（ドラッグは別ページを作ることがある）
5. 挿入した画像を右クリック → **「画像を背景として設定」** で全面（フルブリード）になる
6. 最後に**ページ数とメモ欄の文字数を必ず検証する**。画像操作でメモは消えないが、ページ落ちは起きうる

## 全般

- ページ数が変わる操作をしたら、その場で `x/N` を確認する
- 失敗したら `cmd+z` で戻せる。戻したあとも必ずページ数を見る
